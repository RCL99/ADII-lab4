# Отчет по лабораторной №4

## Данные и подготовка

Рассматривался датасет `german.csv`. Общий объем выборки составляет 1000 строк, количество признаков равно 20. Целевой
признак `Creditability` принимает два значения. Класс 1 соответствует хорошему заемщику, таких объектов 700. Класс 0
соответствует плохому заемщику, таких объектов 300. Наблюдается дисбаланс классов примерно 7 к 3. Каждый признак имеет
числовой формат.

Выполнено разделение данных на train и test в пропорции 80/20. Размер обучающей части составил 800 строк, размер
проверочной части равен 200 строкам. Использовался параметр `random_state=42`. Дополнительно применялась стратификация
`target`. Такой выбор обеспечил сохранение доли классов в обеих частях. Test не использовался до финального этапа. Его
назначение состоит только в финальной проверке.

Предобработка не выполнялась. Пропусков нет, а для деревьев масштаб признаков не имеет значения.

## Гипотезы и эксперименты

Random Forest представляет собой сборку деревьев. Ожидалось, что такой подход окажется устойчивее одиночного дерева.
На результат влияют глубина дерева и минимальный размер листа. Cлишком простые деревья не выявляют закономерности, а
слишком сложные запоминают train.

Рассматривалось применение трех конфигов. Первый конфиг использует `depth=4` и `leaf=10`. Второй конфиг имеет `depth=8`
и `leaf=5`. Третий конфиг задан параметрами `depth=12` и `leaf=10`.

Сравнение выполнялось только на train. Применялась схема `StratifiedKFold` с 5 фолдами. На каждом шаге модель обучалась
на 4 частях и проверялась на оставшейся. Затем выполнялось усреднение метрик. Выбор основывался на среднем roc-auc. Test
в выборе не участвовал.

Для перебора использовался `cross_validate` из sklearn. Финальная проверка возложена на `run_ensemble_experiment`. Эта
функция является сдаваемой. Она обучает выбранный конфиг на всех 800 train-строках и один раз вычисляет метрики на 200
test-строках. Участие указанных строк в CV и выборе не предусматривалось.

## Выбранная модель

Выбор остановлен на Random Forest с 300 деревьями. Параметр `max_depth` равен 8, параметр `min_samples_leaf` равен 5.
Значение `random_state` равно 42, порог классификации равен 0.5. На CV данный конфиг показал лучший ROC-AUC 0.7777.
Конфиг `depth=4` дал 0.7678 и оказался слишком простым. Конфиг `depth=12` дал 0.7733, прироста от увеличения глубины не
наблюдается.

Формирование вероятностей выполняется через `predict_proba`. Класс определяется по порогу 0.5. ROC-AUC рассчитывается по
вероятностям, как требует задание.

## Выводы и ограничения

Настройка глубины и размера листа дала небольшой прирост. Лучший конфиг обошел простой на 0.0099 ROC-AUC. Увеличение
глубины до 12 не улучшило результат. Поэтому усложнение модели не потребовалось.

Ограничение связано с малым объемом данных. Выборка содержит 1000 строк, проверочная часть содержит 200 строк. Разница
между конфигами меньше разброса по фолдам. Порог 0.5 не подбирался под стоимость ошибок. При другом разбиении абсолютное
значение метрик может измениться. Порядок моделей, вероятно, сохранится.

Test не использовался для обучения и выбора параметров. Он применялся только для финальных метрик.

## Воспроизводимость

Запуск выполняется командой `python run_experiments.py`. Скрипт рассчитывает CV, затем вызывает
`run_ensemble_experiment` на test и обновляет `experiment_results.json`. Время работы составляет около 15 секунд.

Окружение: Python 3.14.4, NumPy 2.5.4, Pandas 3.1.0, scikit-learn 1.9.1. Seed равен 42. Разбиение задано параметрами
`test_size=0.2` и `stratify=target`. Для CV используется `StratifiedKFold` с 5 фолдами, `shuffle=True` и
`random_state=42`. Параметризация финальной модели выполнена в `model_init`. Набор конфигов находится в `CONFIGS` в
`run_experiments.py`. Каждое число в отчете соответствует `experiment_results.json`.
